- 14일: 2026-08-15 — 색인, 대표·보조·다리 검색어 노출, 의도한 페이지 노출 여부

- 56일: 2026-09-26 — 유지·확장·재작성 결정과 2차 개편 글 선정

다리 검색어는 `발달장애 학습`, `발달장애 성장`, `발달장애 문해력 교육`, `발달장애 AI 교육`을 우선 확인한다. 넓은 검색어에서 노출되더라도 글이 실제로 다루는 지적장애 범위와 검색 의도가 맞는지 함께 검토한다.

각 검토에서는 Search Console 화면의 기간과 최종 업데이트 시간을 함께 기록한다. 검색어가 공개되지 않을 정도로 표본이 작으면 순위 수치보다 노출 페이지와 전체 노출 추세를 먼저 본다.
